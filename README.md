# Music Production Database

## 📌 Project Overview

The **Music Production Database** is a SQL-only database project designed to model and manage data related to music production. The database organizes information about artists, producers, studios, albums, tracks, and recording sessions in a structured and efficient way.

This project focuses purely on **relational database design and SQL**, without using any external programming languages or frameworks.

---
## 🛠️ Technologies Used

* **SQL** (Structured Query Language)
* **SQL Server**
* **SQL Benchmark Tools**

---
## 🗂️ Database Features

* Well-structured relational schema
* Use of **primary keys** and **foreign keys**
* Support for **one-to-many** and **many-to-many** relationships
* Data integrity enforced through constraints
* Optimized for querying music production data

---
## 🧱 Database Structure

The database includes (but is not limited to) the following entities:

* **Artists** – Stores artist information
* **Producers** – Stores producer details
* **Studios** – Recording studio data
* **Albums** – Album metadata
* **Tracks** – Individual songs
* **Recording Sessions** – Links artists, producers, studios, and tracks

Relationships are handled using foreign keys and junction tables where necessary.

---
## 🔍 Example SQL Operations

The project supports SQL operations such as:

* Creating tables
* Inserting records
* Updating data
* Deleting records
* Complex queries using:

  * `JOIN`

  * `HAVING`
